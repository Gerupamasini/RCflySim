# RCflySim（屋内ラジコン飛行シミュレータ）

■ はじめかた（Windows 10 / 11）
1. この zip を右クリック →「すべて展開」で好きな場所に展開する（zip の中から直接起動しない）
2. 展開したフォルダの Setup.exe をダブルクリック →「インストール」
   ・Python 3.10〜3.13 が必要。無ければ画面の「Python をインストール」ボタンで入る
   ・初回はインターネットから必要なライブラリを取ってくる（数分）
   ・オプションでデスクトップ / スタートメニューにショートカットを作れる
3. ESP32FlightSim.exe（またはショートカット）で起動

■ 「Windows によって PC が保護されました」と出たら
  署名のない自作ソフトなので出ることがある。「詳細情報」→「実行」で起動できる

■ 操作
  Xbox コントローラ（ボタンを 1 回押すと認識）かキーボード。H キーで操作方法、
  右パネルで機体（5 種類）・舵の効き・カメラ・立ち位置を変えられる。詳しくは README.md
